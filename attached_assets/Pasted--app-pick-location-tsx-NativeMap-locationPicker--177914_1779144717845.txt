Полностью перепиши app/pick-location.tsx и компонент NativeMap в режиме locationPicker. Цель — сделать как в Яндекс Еде и ВкусВилл.
Логика работы:

Карта на весь экран
При открытии — автоматически определяется геолокация через navigator.geolocation внутри WebView
Маркер 📍 фиксирован по центру CSS overlay
Карта двигается под маркером
Адрес обновляется в реальном времени через Яндекс reverse geocoding прямо внутри WebView
Адрес отображается в строке сверху поверх карты
Одна кнопка «Подтвердить адрес» снизу поверх карты
Никаких внешних кнопок геолокации — только стрелка геолокации встроенная в Яндекс карту через ymaps.control.GeolocationControl

  <script>
    var currentLat = 55.7558;
    var currentLng = 37.6173;
    var geocodeTimer = null;
    var map;

    function reverseGeocode(lat, lng) {
      clearTimeout(geocodeTimer);
      geocodeTimer = setTimeout(function() {
        ymaps.geocode([lat, lng], { results: 1, kind: 'house' }).then(function(res) {
          var obj = res.geoObjects.get(0);
          if (obj) {
            var address = obj.getAddressLine();
            var city = '';
            var components = obj.properties.get('metaDataProperty.GeocoderMetaData.Address.Components') || [];
            for (var i = 0; i < components.length; i++) {
              if (components[i].kind === 'locality') {
                city = components[i].name;
                break;
              }
            }
            document.getElementById('address-text').textContent = address;
            document.getElementById('address-sub').textContent = city;
            currentLat = lat;
            currentLng = lng;
            window.ReactNativeWebView.postMessage(JSON.stringify({
              type: 'addressUpdated',
              latitude: lat,
              longitude: lng,
              address: address,
              city: city,
            }));
          }
        });
      }, 500);
    }

    ymaps.ready(function() {
      map = new ymaps.Map('map', {
        center: [currentLat, currentLng],
        zoom: 16,
        controls: ['geolocationControl', 'zoomControl'],
      });

      // Отступ сверху для address bar
      map.margin.addArea({ top: 80, left: 0, right: 0, bottom: 80 });

      // При движении карты
      map.events.add('actionend', function() {
        var center = map.getCenter();
        reverseGeocode(center[0], center[1]);
      });

      // Геолокация через Яндекс встроенный контрол
      var geolocationControl = map.controls.get('geolocationControl');
      geolocationControl.events.add('locationchange', function(e) {
        var position = e.get('position');
        map.setCenter(position, 16);
        reverseGeocode(position[0], position[1]);
      });

      // Автоопределение при старте
      ymaps.geolocation.get({ provider: 'browser', mapStateAutoApply: false }).then(function(result) {
        var pos = result.geoObjects.get(0);
        if (pos) {
          var coords = pos.geometry.getCoordinates();
          map.setCenter(coords, 16);
          reverseGeocode(coords[0], coords[1]);
        }
      }).catch(function() {
        reverseGeocode(currentLat, currentLng);
      });

      // Если переданы начальные координаты
      var initLat = window.initialLat;
      var initLng = window.initialLng;
      if (initLat && initLng) {
        map.setCenter([initLat, initLng], 16);
        reverseGeocode(initLat, initLng);
      }
    });

    document.getElementById('confirm-btn').addEventListener('click', function() {
      var center = map.getCenter();
      window.ReactNativeWebView.postMessage(JSON.stringify({
        type: 'confirmed',
        latitude: center[0],
        longitude: center[1],
      }));
    });
  </script>

В NativeMap.tsx в режиме locationPicker:

Замени API_KEY_PLACEHOLDER на реальный ключ из process.env.EXPO_PUBLIC_YANDEX_MAPS_API_KEY
Если переданы initialLat/initialLng — инжектируй их как window.initialLat и window.initialLng через injectedJavaScriptBeforeContentLoaded
В onMessage обрабатывай:

addressUpdated → вызывай onLocationSelected с координатами и адресом
confirmed → вызывай onConfirm если передан



В app/pick-location.tsx:

Убери всю логику expo-location и внешнего reverse geocoding — всё происходит внутри WebView
Убери кнопку «Определить автоматически» — геолокация встроена в карту
Убери отдельную строку адреса снаружи WebView — адрес отображается внутри карты
Экран просто рендерит <NativeMap mode="locationPicker" /> на весь экран
При onConfirm — сохраняет координаты и возвращается назад через router.back()
